# Desafio 12 - Condiciones

Este proyecto es un desafío práctico correspondiente al curso de Desarrollo Web Frontend del PEAM (UNSE).

El objetivo del trabajo es implementar tres funcionalidades interactivas independientes: alternar el estilo del borde de una imagen al hacer clic, calcular y validar una cantidad máxima permitida de stickers a partir de valores numéricos ingresados, y construir un simulador de ingreso de contraseña que verifique combinaciones específicas mediante menús desplegables.

Para su construcción se utilizaron tecnologías como HTML, CSS (apoyado en Bootstrap para la estructura visual) y JavaScript, haciendo especial énfasis en la manipulación del DOM mediante querySelector, .value e innerHTML para acceder, capturar y modificar elementos de la interfaz en tiempo real. Además, se incorporó el manejo de eventos de usuario (onclick) en botones y elementos multimedia, implementando la lógica necesaria mediante estructuras condicionales (if, else if, else), transformación de tipos de datos numéricos y operadores de comparación para evaluar las entradas del usuario y entregar las respuestas correctas.
